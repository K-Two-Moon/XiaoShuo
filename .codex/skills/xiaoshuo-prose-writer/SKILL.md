# 小说正文生成工作流

## 生成前必须读取

先打开 [`references/setting-files.md`](references/setting-files.md)，按照其中的清单读取所有已配置的设定资料。该清单中的路径是相对于仓库根目录的路径。

## 工作流程

1. 明确目标章节、生成范围、叙事视角、目标字数和写入位置。
2. 读取设定清单中所有标记为“必读”的文件；再读取目标章节的章节拆分、大纲或摘要。
3. 读取正文中紧邻目标位置的上一章，必要时读取下一章，提取人物状态、时间、地点、未解决冲突和承接句。
4. 生成正文前列出本次必须遵守的事实约束；发现设定冲突时暂停并说明冲突来源。
5. 生成或修改正文，保持既定视角、语气、节奏和章节结构，不引入无法从设定或情节推导出的关键事实。
6. 生成后检查人物行为、时间线、地点移动、能力规则、道具状态和伏笔回收，修正明显矛盾。
7. 用户要求写回文件时，沿用现有目录和命名格式；否则只在回复中输出正文，不擅自创建或覆盖文件。

## 输出约束

- 使用中文正文，不输出分析过程、设定清单或元叙事内容，除非用户要求。
- 不把摘要、章节拆分或设定说明原样扩写成流水账；将其转化为场景、行动、对话和感官细节。
- 不擅自改变已经确定的人物关系、关键事件顺序、世界观规则或叙事视角。
- 如果必读资料缺失、路径未填写或文件无法读取，先报告缺失项，再询问是否继续生成。
